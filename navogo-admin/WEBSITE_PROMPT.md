# 🚀 Prompt para Crear Sitio Web Promocional de DAWZ

## 📋 Descripción General del Proyecto

Necesito crear un sitio web profesional y moderno para promocionar **DAWZ**, una plataforma SaaS integral para la gestión de restaurantes, cafeterías y negocios de alimentos. El sitio debe ser atractivo, convertir visitantes en clientes, y comunicar claramente el valor de nuestro producto.

---

## 🎯 Objetivo del Sitio Web

Crear una landing page/sitio web que:
- **Presente** la plataforma DAWZ de manera profesional y atractiva
- **Convierta** visitantes en usuarios registrados o solicitudes de demo
- **Explique** las funcionalidades principales y beneficios del sistema
- **Transmita** confianza y profesionalismo
- **Muestre** casos de uso y testimonios (opcional)
- **Facilite** el contacto y registro

---

## 🏢 Sobre DAWZ - Información del Producto

### ¿Qué es DAWZ?
**DAWZ** es una plataforma web integral diseñada para restaurantes, cafeterías, bares y negocios de alimentos que buscan digitalizar y optimizar sus operaciones. Es un sistema todo-en-uno que elimina la necesidad de múltiples aplicaciones.

### Público Objetivo
- Dueños de restaurantes pequeños y medianos
- Gerentes de cafeterías y bares
- Emprendedores del sector alimentos
- Cadenas de restaurantes buscando centralizar operaciones
- Negocios que quieren ofrecer menú digital a sus clientes

### Propuesta de Valor Principal
"**Gestiona tu negocio de alimentos desde una sola plataforma**: pedidos, mesas, inventario, ventas y menú digital para tus clientes."

## ✨ Funcionalidades Principales a Destacar

### 1. 📱 Menú Digital Público
- Menú digital tipo food delivery para clientes finales
- Diseño mobile-first inspirado en Uber Eats/Rappi
- Sin necesidad de app o login para los clientes
- Integración directa con WhatsApp para pedidos
- Compartir en redes sociales
- URL personalizada por negocio (slug único)
- **Beneficio**: Tus clientes pueden ver tu menú desde cualquier dispositivo sin instalar nada

### 2. 🪑 Gestión de Mesas (Para Restaurantes)
- Vista visual de todas las mesas del local
- Estados: Disponible, Ocupada, Reservada, En Limpieza
- Asignación de pedidos a mesas
- Control de capacidad y tiempos
- Diseño visual intuitivo con estados de color
- **Beneficio**: Control total del salón en tiempo real

### 3. 📦 Gestión de Pedidos
- Dashboard central de todos los pedidos
- Filtros por estado: Pendiente, En Proceso, Completado, Cancelado
- Vista detallada de cada pedido
- Notificaciones en tiempo real
- Histórico completo
- **Beneficio**: Nunca pierdas un pedido, todo centralizado

### 4. 💰 Punto de Venta (POS)
- Sistema de ventas en mostrador
- Carrito de compras intuitivo
- Múltiples métodos de pago
- Generación de tickets/facturas
- Cálculo automático de totales e impuestos
- **Beneficio**: Cobra más rápido y sin errores

### 5. 📊 Dashboard de Ventas y Reportes
- Estadísticas en tiempo real
- Gráficos de ventas diarias, semanales, mensuales
- Productos más vendidos
- Análisis de ingresos
- Exportación a Excel y PDF
- **Beneficio**: Toma decisiones basadas en datos reales

### 6. 🍔 Gestión de Productos y Categorías
- Catálogo completo de productos
- Organización por categorías
- Precios, descripciones, imágenes
- Productos destacados/promociones
- Activar/desactivar productos fácilmente
- **Beneficio**: Actualiza tu menú en segundos

### 7. 🏪 Multi-Empresa
- Gestiona múltiples negocios desde una cuenta
- Configuración independiente por negocio
- Horarios de operación personalizables
- Logo y branding propio por empresa
- **Beneficio**: Ideal para cadenas o propietarios con varios locales

### 8. 👥 Gestión de Usuarios y Roles
- Control de acceso por roles
- Usuarios administradores y empleados
- Permisos personalizables
- Auditoria de acciones
- **Beneficio**: Seguridad y control de tu equipo

### 9. 📍 Configuración de Zonas de Envío
- Define áreas de cobertura
- Costos de envío por zona
- Mapa visual interactivo
- **Beneficio**: Optimiza tus entregas y costos

### 10. 📢 Gestión de Publicidad
- Banners promocionales
- Destacar productos
- Campañas especiales
- **Beneficio**: Aumenta ventas con promociones efectivas

## 🎨 Diseño y Estilo Visual

### Identidad de Marca
- **Colores principales**: Gradiente morado moderno (#667eea → #764ba2)
- **Colores secundarios**: 
  - Verde para éxito: #4caf50
  - Rojo para alertas: #dc3545
  - Azul para acciones: #007bff
  - Gris claro para fondos: #f4f5f7

### Estilo de Diseño
- **Moderno y limpio**: Inspirado en SaaS modernos como Stripe, Notion
- **Mobile-first**: Totalmente responsive
- **Animaciones suaves**: Transiciones, hover effects, scroll animations
- **Glassmorphism**: Efectos de vidrio en algunos elementos (opcional)
- **Minimalista**: Mucho espacio en blanco, tipografía clara

### Tipografía
- **Principal**: Inter, Poppins, o similar sans-serif moderna
- **Secundaria**: Para títulos grandes, considerar una fuente bold

### Componentes Visuales
- Botones con degradado y efectos hover
- Cards con sombras sutiles y hover elevation
- Iconos: Material Icons o Heroicons
- Imágenes: Screenshots del dashboard real (cuando estén disponibles)
- Mockups: Mostrar la interfaz en diferentes dispositivos

## 🛠️ Stack Tecnológico Recomendado

### Opción 1: Landing Page Estática (Más Rápido para Lanzar)
**Ideal para**: Lanzar rápido con presupuesto limitado

**Stack:**
- **Framework**: Astro, Next.js, o HTML/CSS/JS puro
- **Styling**: Tailwind CSS (recomendado) o SCSS
- **Animaciones**: Framer Motion, AOS (Animate On Scroll)
- **Formularios**: Formspree, FormSubmit, o Netlify Forms
- **Hosting**: Vercel, Netlify, o GitHub Pages (gratis)
- **Analytics**: Google Analytics o Plausible

**Ventajas:**
- ✅ Carga ultra rápida
- ✅ SEO optimizado
- ✅ Hosting gratis
- ✅ Deploy en minutos

### Opción 2: React/Next.js con Backend (Más Robusto)
**Ideal para**: Si necesitas formularios de registro complejos, blog, o área de clientes

**Stack:**
- **Frontend**: Next.js 14+ (React)
- **Styling**: Tailwind CSS + shadcn/ui components
- **Animaciones**: Framer Motion
- **Backend**: Next.js API Routes o Supabase
- **Base de datos**: PostgreSQL (Supabase) o Firebase
- **Auth**: NextAuth.js, Supabase Auth, o Clerk
- **Email**: Resend, SendGrid
- **Hosting**: Vercel
- **CMS (opcional)**: Sanity, Contentful para blog

**Ventajas:**
- ✅ Escalable
- ✅ Permite área de clientes/login
- ✅ Blog integrado
- ✅ APIs propias

### Opción 3: WordPress (Si prefieres CMS tradicional)
**Ideal para**: No-code/low-code, necesitas editar contenido frecuentemente

**Stack:**
- **CMS**: WordPress
- **Builder**: Elementor Pro o Divi
- **Theme**: Astra, GeneratePress, o custom
- **Hosting**: WP Engine, SiteGround, Hostinger
- **Plugins**: Yoast SEO, Contact Form 7, WPForms

**Ventajas:**
- ✅ Fácil de editar sin código
- ✅ Muchos plugins disponibles
- ✅ Familiar para muchos

**Desventajas:**
- ❌ Más lento que opciones estáticas
- ❌ Requiere mantenimiento (actualizaciones)

### ⭐ Recomendación Personal
Para un sitio promocional de DAWZ, recomiendo **Next.js + Tailwind CSS**:
- Performance excelente
- SEO optimizado out of the box
- Fácil de escalar (agregar blog, área de clientes después)
- Deploy gratis en Vercel
- Moderno y mantenible

## 📱 Consideraciones Mobile

### Mobile-First Design
- Diseñar primero para móvil, luego escalar a desktop
- Menú hamburguesa colapsable
- Botones grandes y fáciles de tocar (min 44x44px)
- Formularios simples y autocompletables
- CTAs sticky en mobile (botón flotante)

### Performance Mobile
- Imágenes optimizadas (WebP, lazy loading)
- Iconos SVG en lugar de fuentes de iconos
- Minimizar animaciones pesadas
- Critical CSS inline
